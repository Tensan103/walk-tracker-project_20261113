Phase 3までの全ステップ完了、お疲れ様です。
現在のサーバーレス構成（API Gateway / Lambda / DynamoDB / Cognito / S3+CloudFront）は基本的に使った分だけの課金で非常に安価ですが、「検証用の設定のまま放置すると本番で事故が起きるポイント」がいくつかあります。

本番運用・長期検証に入る前に、最低限チェックしておくべき項目を4つの領域にまとめました。

---

## 1. データ保護・バックアップ（最優先）

検証フェーズで設定した「消しやすい構成」を、本番向けの「消えない構成」へ切り替えます。

* **CDKの `RemovalPolicy` を `RETAIN` に変更**
* 現在、`WalkEventsTable`・`DevicesTable`・`Cognito User Pool` は `RemovalPolicy.DESTROY` になっています。誤ってスタック削除やテーブル再作成が走った際に全データが消えるため、本番では **`RemovalPolicy.RETAIN`** に変更してください。


* **DynamoDB の PITR（ポイントインタイムリカバリ）を有効化**
* CDKのテーブル定義に `pointInTimeRecovery: true`（または `pointInTimeRecoverySpecification: { pointInTimeRecoveryEnabled: true }`）を追加します。過去35日間の任意の秒単位の状態へ復元でき、バグによる誤削除やデータ破損から守れます。


* **古い歩行ログの自動削除（TTL）の検討**
* 現在の `GET /events` は `Scan` で全件取得しています。長期運用で数万件に膨らむと表示遅延と課金増につながるため、不要になった過去ログ（例：1年経過後）を自動削除する **DynamoDB TTL** の導入を検討しておくと安心です。



---

## 2. コスト監視・ログ肥大化対策

* **AWS Budgets で予算アラートを設定（AWSコンソール）**
* 万が一のループバグや不正アクセスによる課金爆発にすぐ気づけるよう、AWS Budgets で「月額 $5〜$10」程度の予算を設定し、**実績・予測が80%を超えたらメール通知**されるようにしておきます（無料枠内で設定可能）。


* **CloudWatch Logs の保持期間（Retention）を設定（CDK）**
* Lambda のロググループはデフォルトで「無期限保存」になっており、放置するとログストレージ代がじわじわ積み上がります。CDKの各Lambda定義に `logRetention: logs.RetentionDays.ONE_MONTH`（または `THREE_MONTHS`）を追加して古いログを自動削除させてください。


* **Usage Plan のクォータ見直し**
* Step 3-1 で設定した `POST /events` の月間クォータ（例：10,000回）が、運用予定の端末台数 × 1日の検知回数に対して十分か（逆に大きすぎないか）を確認します。



---

## 3. セキュリティの引き締め

* **CORS のオリジンを CloudFront の URL に限定**
* 現在、API Gateway と Lambda のレスポンスヘッダーは `Access-Control-Allow-Origin: "*"` になっています。本番運用では、管理画面の `WEB_URL`（`[https://xxxx.cloudfront.net](https://xxxx.cloudfront.net)`）のみを許可するよう絞り込むのが安全です。


* **Cognito 管理者アカウントの MFA（多要素認証）**
* 業務データ（誰がいつ歩きスマホをしたか）を扱うため、本番用の管理者アカウントには Cognito の TOTP（Google Authenticator 等）による MFA を有効化しておくと堅牢です。


* **ローカル環境ファイルの管理**
* `.env` や `android-app/local.properties` に `API_KEY` の実値が保存されているため、引き続き Git の追跡対象外であることを維持してください。



---

## 4. 障害検知（最低限の監視）

* **Lambda エラーのアラート通知（CloudWatch Alarm + SNS）**
* 普段は管理画面を見ない日でも障害に気づけるよう、各Lambdaの `Errors` メトリクスが「5分間に1回以上」発生したらメール通知するアラームを1つ仕込んでおくと、実運用での安心感が大きく変わります。
