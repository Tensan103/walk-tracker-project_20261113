# タスク: 管理画面 (React) におけるデバイス(ユーザー)管理機能の実装

## 1. 目的と背景
バックエンドに追加された `/devices` API と連携し、管理者が「誰に・どの端末（デバイスID）を割り当てるか」をWebブラウザ上から登録・編集・削除・一覧表示できるダッシュボード機能（デバイス管理画面）を実装する。

## 2. 対象コンポーネント
- `/admin-web-viewer` 配下のReactファイル群
  - `package.json` (必要に応じてライブラリ追加)
  - `src/App.tsx` (ルーティングの追加)
  - `src/components/` または `src/pages/` (新規作成するUI群)

## 3. 実装要件

### 3-1. 画面のルーティング（タブ切り替え）追加
- 既存の「歩行検知履歴（ダッシュボード）」画面と、新規作成する「デバイス管理」画面を切り替えられるようにする。
- 規模が小さいため `react-router-dom` を導入するか、シンプルに `useState` によるタブ切り替えで実装するかは、プロジェクト構成のシンプルさを考慮して最適な手法を選択すること。
- 画面上部または左側にナビゲーションメニュー（ヘッダー/サイドバー）を配置すること。

### 3-2. デバイス管理画面 (DevicesScreen) の実装
以下のUI要素とAPI連携を実装する。APIのベースURLは環境変数または定数（既存の `API_URL` に `/devices` を付与したもの）を利用する。

#### ① 一覧表示 (Read)
- `GET /devices` を呼び出し、結果をテーブル形式で表示する。
- 表示項目: `デバイスID`, `ユーザー名 (userName)`, `端末モデル (deviceModel)`, `登録日時`、および「操作（編集/削除）」列。

#### ② 新規登録 (Create)
- テーブルの上部に「新規デバイス登録」フォーム（またはボタンで開くモーダル）を配置する。
- 入力項目:
  - `デバイスID` (管理者が任意の英数字を入力、またはUUIDを自動生成するボタンを配置)
  - `ユーザー名` (テキスト)
  - `端末モデル` (テキスト)
- `POST /devices` を呼び出して登録後、一覧を再取得（リロード）する。

#### ③ 編集 (Update) と 削除 (Delete)
- **編集**: 一覧の「編集」ボタンを押すと、対象行の `ユーザー名` や `端末モデル` を変更できるフォーム（またはモーダル）を開き、`PUT /devices` で更新する。
- **削除**: 「削除」ボタンを押すと確認ダイアログ（`window.confirm` 等）を出し、OKなら `DELETE /devices/{deviceId}` を呼び出して一覧から消去する。

### 3-3. UI/UXの考慮
- API通信中はローディング表示（「読み込み中...」等）を出すこと。
- エラー発生時（ネットワークエラー等）は、画面上にエラーメッセージを表示して管理者が視認できるようにすること。
- デザインはCSSモジュールやインラインスタイル、またはシンプルなUIライブラリを利用して、管理画面らしく見やすく整えること。

## 4. 実行手順
1. ブランチ `feature/admin-devices-crud` を作成して切り替える。
2. 上記の要件に従い、Reactコードの追加・改修を行う。
3. `cd admin-web-viewer` にて `npm run dev` を実行し、開発用サーバーでローカルテストができる状態にする。
4. ※バックエンド（AWS API Gateway）側でCORSエラーが出た場合は、バックエンドのCDKコードに戻ってCORS設定を見直すこと。
5. 正常にCRUD処理が動くことを確認したら、コミットして完了を報告する。
